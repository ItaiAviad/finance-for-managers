ערך נוכחי של סכום יחיד

כמה שווה היום סכום שיתקבל בעתיד: PV = FV × (1 + r)−t.

דוגמה: 5,000 ש״ח בעוד 3 שנים, בריבית 10%: PV = 5,000 × (1 + 10%)−3 = 3,756.57.
ערך נוכחי של סדרה

כמה שווים היום תשלומים שווים בתום כל תקופה: PV = PMT × 1 − (1 + r)−tr. הנוסחה מובילה תקופה אחת לפני התשלום הראשון.

דוגמה: 5,000 ש״ח בתום כל אחת מ-3 שנים, בריבית 10%: PV = 5,000 × 2.486852 = 12,434.26.
ערך נוכחי של זרם אינסופי

תשלום קבוע לנצח: PV = PMTr, תקופה אחת לפני התשלום הראשון.

דוגמה: 1,000 ש״ח בכל שנה לנצח, בריבית 10%: PV = 1,0000.10 = 10,000.
דגש: אין ביחידה הזאת נוסחת היוון חדשה. יש כלל החלטה חדש: משווים את הערך הנוכחי של מה שמקבלים לסכום שמשלמים היום.
איך קוראים את PVFA?

PVFA(r,t) הוא קיצור של המקדם 1 − (1 + r)−tr, ״מקדם ערך נוכחי סדרתי״. למשל PVFA(10%,3) = 2.486852.

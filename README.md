# מימון למנהלות ומנהלים

אתר הקורס: https://shaytsaban.github.io/finance-for-managers/

- `index.html`: דף הבית.
- `lectures/lecture-1/`: מצגת השיעור וסיכום PDF.
- `_build/`: מקורות הבנייה. `python3 autofit.py` בונה את המצגת ומחלק פתרונות ארוכים לשקפים; `python3 build_summary.py` בונה את הסיכום; `python3 test_deck.py` ו-`python3 check_equations.py` בודקים. פונטי David נטענים מ-`../iit-build/fonts` ואינם נשמרים כאן.
